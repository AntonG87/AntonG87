### About

I build web products end to end — from the data model to the interface people actually click.
Most of my day-to-day work is **TypeScript on Next.js** with **Prisma** over PostgreSQL, plus production **WordPress** for client sites. When a job needs to live on the desktop, I reach for **C# / WPF**.

- Currently building **[Codearia Academy](https://academy.codearia.com/)** — a learning platform about AI tooling for developers.
- Interested in what makes apps fast: caching strategies, killing N+1 queries, moving work off the critical path.
- Based in Haifa, Israel. Open to fullstack and frontend work.
